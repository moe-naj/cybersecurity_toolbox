# Cybersecurity Toolbox

A personal, living reference of every cybersecurity tool I've used or evaluated — organized by use case rather than alphabetically, so it's easy to scan for "what do I reach for on X kind of job" instead of hunting an A-Z list from memory.

## How it's organized

The table is sorted by **Scope** (the use case or domain a tool belongs to — e.g. Memory, Network, Disk, Registry, Timeline, Malware, OSINT) rather than by tool name. Each entry includes a short description of what the tool does and, where useful, a concrete example command to get started.

This list spans the full range of offensive and defensive security work — reverse engineering, DFIR, memory/disk forensics, network analysis, Active Directory, cloud, malware analysis, OSINT, and phishing/adversary simulation tooling.

## Disclaimers

- **For educational and authorized use only.** Several tools listed here (e.g. credential-dumping, phishing-simulation, or exploitation frameworks) are dual-use and intended strictly for authorized security testing, research, and defensive purposes — not for use against systems or accounts you don't have explicit permission to test.
- **No warranty, no endorsement.** This is a personal reference, not a vetted or audited recommendation list. Tool behavior, licensing, and maintenance status can change — always verify a tool's current state, license, and source before running it in a real environment.
- **Sourced from public/official releases only.** Always download tools from their official repositories or vendor sites, not third-party mirrors.
- **Descriptions reflect my own understanding at time of writing** and may not capture every feature, edge case, or newer alternative — treat this as a starting point for research, not a definitive technical reference.
- **This list is a work in progress** and updated as I use new tools or retire outdated ones; some entries may reference legacy tools that have since been superseded.
